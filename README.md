# YourShortener (WIP)

Get your own URL shortener up and running.

## Development

Clone the repository and run the application locally.

### Prerequisites
  - .NET SDK 10 or later
  - PostgreSQL 18 or later

### How to run
```bash
# Clone the repository
git clone https://github.com/Shtskkh/YourShortener.git

# Navigate to the project directory
cd YourShortener

# Restore dependencies
dotnet restore

# Build and run
dotnet run
```
